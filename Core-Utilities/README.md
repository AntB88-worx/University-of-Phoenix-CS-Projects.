# 🐍 Core Utilities & Operational Automation

This directory houses advanced system utilities and automation scripts designed for optimizing logistics, data manipulation, and computational efficiency.

---

### 🧠 Key Engineering Focus
*   **Control Flow & Automation:** Utilizing complex conditional branching, loops, and terminal management [INDEX].
*   **Functional Programming:** Implementing modular, reusable functions and automated alert systems [INDEX].
*   **Data Processing:** Managing numerical constraints, type casting, and real-time screen updates [INDEX].

---

### 📂 Project Highlights

*   📈 **Student Performance Tracker (`grade_calculator.py`):** Calculates academic averages, filters data, and flags performance metrics [INDEX].
*   🌡️ **Computational Metric Converter (`TempConverter.java`):** Maps Fahrenheit benchmarks to Celsius using Java static methods and array iteration [INDEX].
*   🔢 **Bits & Bytes Converter (`data_converter.py`):** Translates raw byte data into various scales (KB/MB) for storage visualization [INDEX].
*   🏭 **Supply Chain Control Tower Engine (`clock.py`):** Simulates real-time, multi-hub logistics freight movement [INDEX].
*   ⏳ **Operational Milestone Analyzer (`countdown.py`):** Tracks distribution deadlines and calculates financial liability for SLA breaches [INDEX].
*   📅 **Enterprise Capacity Planner (`calendar_view.py`):** Generates a 12-month calendar with embedded Q4 logistics forecasts [INDEX].
*   📝 **Logic Notes (`5-Week-Logic.txt`):** Documentation on structural logic and curriculum milestones [INDEX].

---

### 💻 Execution Instructions

To run the Python automation scripts:
```bash
python grade_calculator.py
python data_converter.py
python clock.py
python countdown.py
python calendar_view.py
```

To compile and run the Java component:
```bash
javac TempConverter.java
java TempConverter
```
